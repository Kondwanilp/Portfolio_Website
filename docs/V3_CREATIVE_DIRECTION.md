# Portfolio V3 - Fieldwork

## The decision

Fieldwork is Kondwani Phiri's personal scientific workspace: a quiet native-application frame containing research notebooks, personal field notes, photographic collections and distinct off-duty spaces. The palette stays parchment, ivory, ink, sage, teal, cyan, amber and obsidian. The V2 full-screen biological entrances and cover/directory composition are replaced. Biology becomes a way to organize inquiry, methods and connections, not a set of loading sequences.

## Information architecture

The source-list sidebar groups a welcome workspace, About, Research, Experience, Leadership, Photographs and Journal; an off-duty group opens Listening Room, Chess Corner and Court Vision. All are real URLs with active selection and direct loading. A contextual toolbar identifies the current collection and makes the actual resume immediately available. Mobile uses a compact accessible collection menu and a single reading pane. There is no fake desktop, dock, traffic-light ornament or nonfunctional window control.

## The welcome workspace

A concise identity panel uses the real portrait, name, Grambling Biology/Computer Science identity, Lusaka origins, signature expression and resume access. A small research-file list opens actual cases; a compact off-duty shelf communicates music, chess and basketball. It is a useful start surface, not the old tall hero followed by repeated biography and timeline content.

## Research as original scientific case files

A collection index presents the three authentic research experiences. A selected document gives the question, context, contribution, methods, real photographs, posters and documented qualifications. Technique selection reveals genuine cross-project relationships. A PI can scan the collection or read a whole case without decoding an experimental graph. Native details and normal links remain useful before JavaScript. Case selection supports URL/hash history and keyboard access. No findings, counts, oncology experience or laboratory records are invented.

## Personal and off-duty collections

About is an honest profile and narrative. Experience/leadership retain their authentic chronological record. Photographs form a field contact sheet with captions and inspection tools. Journal displays only actual published work and a truthful empty state. Listening Room is an intimate native music ledger, chess a working personal study, and Court Vision a screening space plus basketball journal. Their functioning provider/game/storage/admin code is retained rather than aesthetically rewritten.

## Interface and motion

Use precise source-list alignment, quiet hairline divisions, comfortable 16-18px reading text, compact contextual toolbars and selective translucent material. Typography remains locally hosted and licensed. Shared document windows provide fit, zoom, download, original access, Escape and focus restoration; the existing real CV is mandatory. Small pressed/selected/open states should feel physical. Reduce motion immediately when requested. No mandatory entrance, full-screen organelle curtain, flying-particle gate or public playback control is mounted. Optional scientific exploration can be added only if it supports real content.
